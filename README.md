# 🐤 Floppy Bird

A lightweight Flappy Bird-inspired browser game built from scratch with HTML5 Canvas, CSS and vanilla JavaScript.

## Features

- Smooth gravity and flap physics
- Randomized endless pipes
- Collision detection
- Live score and persistent high score using `localStorage`
- Keyboard, mouse and touch controls
- Pause/resume support
- Responsive design for desktop and mobile
- No frameworks or external dependencies

## Controls

- **Space / Arrow Up** — flap
- **Click / Tap** — flap
- **P** — pause/resume

## Run locally

Open `index.html` in any modern browser.
